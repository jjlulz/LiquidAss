# Liquid Gl(ass) remake [iOS 12]
An iOS 26 Liquid Glass inspired look for iOS 12: Control Center tiles, buttons and sliders,
dock, folders, notification banners, passcode keypad, Spotlight search bar and the lock screen clock.
A rough remake, not the real thing. Rootful jailbreak assumed.
Built for the A8 iPod touch: each glass layer is drawn once into a cached image, so there is no live blur or masking per tile.
